# Hardware Roadmap: The Silicon Mind

## Phase 1: Prototype (Current)
Software-based simulation using synchronous Python loops and Godot physics.

## Phase 2: Embedded Logic (College Year 2-3)
Transitioning the Body State Tracker (BST) to an FPGA (Verilog). By moving metabolic decay to hardware Look-Up Tables (LUTs), we move closer to a clockless, continuous-flow intelligence model.

## Phase 3: Physical Embodiment (Year 4+)
Replacing the Godot simulation with a physical robotic chassis, where "Pain" is real-time sensor feedback and "Energy" is actual battery voltage.
